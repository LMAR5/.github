## :file_folder: Projects
Here you'll find interesting projects like some of the following applications:

### :computer: **Priority Hub**
Priority Hub is a productivity web application that allows users to manage their task, keep track of their time spent, and gain valuable insights through intuitive charts.

- **Type of app:** Single-page application (SPA) web application  
- **Main technologies:** Bootstrap, React, JavaScript, NodeJS, Express, MySQL, AWS  
- **Libraries:** Recharts, React Bootstrap, SweetAlert2  

Check out the project here: [Priority Hub](https://github.com/LMAR5/priority-hub-web)

### :computer: **UNO Multiplayer**
An interactive UNO web application featuring real-time multiplayer gameplay, persistent game sessions via PostgreSQL, and integrated lobby/in-game chat.  

- **Type of app:** Server-side rendering (SRR) web application  
- **Main technologies:** NodeJS, Express, Tailwind CSS, Socket IO, EJS, Postgres  
- **Libraries:** bcrypt, Postgres migrations

Check out the project here: [UNO Multiplayer](https://github.com/LMAR5/uno-game)

### :iphone: **Priority Hub Mobile**
Mobile version of Priority Hub that allows users to manage their tasks with a user-friendly interface and gain insights of their progress through an intuitive dashboard.

- **Type of app:** Swift (iOS) mobile application  
- **Main technologies:** Swift 5, CoreData, SwiftCharts

Check out the project here: [Priority Hub Mobile](https://github.com/LMAR5/PHApp1)  

### :computer: **Formula 1 Analytics Platform**
An interactive F1 analytics platform built with Python and Shiny, featuring custom data pipelines and Plotly dashboards for exploring historical racing performance and trends.  

- **Type of app:** Server-side rendering (SSR) web application  
- **Main technologies:** Python 3, Shiny for Python, Pandas, Plotly, Kaggle dataset

Check out the project here: [F1 Analytics Platform](https://github.com/LMAR5/formula1-analysis)
